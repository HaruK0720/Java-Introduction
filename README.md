Javaをこれから学ぶ方に向けて、基本構文やプログラミングの考え方を、サンプルコードや実行結果を交えながらわかりやすく解説することを目指すアドベントカレンダーです。

変数・データ型・条件分岐・繰り返し処理・配列・メソッド・クラスなど、Javaの基礎を一つずつ取り上げていきたいと考えています。

☕このカレンダーの方針
・Java初心者でも理解できるよう、基礎から丁寧に解説する
・サンプルコードや実行結果を掲載し、動作をイメージしやすくする
・初心者がつまずきやすいポイントや注意点も取り上げる
